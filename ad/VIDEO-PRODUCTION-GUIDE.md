## 1. Project Overview

### Video Specifications
| Parameter | Specification |
|-----------|---------------|
| **Duration** | 60 seconds (main) / 30 seconds (social cut) |
| **Resolution** | 1920×1080 (16:9) + 1080×1920 (9:16 vertical) |
| **Frame Rate** | 30fps minimum, 60fps preferred |
| **Format** | MP4 (H.264 codec) |
| **File Size** | <50MB for web, <100MB for broadcast |

### Brand Guidelines
| Element | Value |
|---------|-------|
| **Primary Color** | Indigo (#4F46E5) |
| **Secondary Color** | Purple (#7C3AED) |
| **Accent Color** | Pink (#EC4899) |
| **Background** | Dark (#0F0D1A) |
| **Text Color** | White (#F8FAFC) |
| **Font** | Inter / Poppins (Bold for headings, Regular for body) |

### Target Audience
- **Primary**: College administrators, IT decision-makers
- **Secondary**: Faculty, students, parents
- **Tone**: Professional, innovative, trustworthy, exciting

## 2. Detailed Storyboard

### SCENE 1 — THE HOOK (0:00 - 0:05)

**Duration:** 5 seconds

**Visual Elements:**
- Black screen fades in
- Single glowing indigo dot appears center screen
- Dot pulses once (scale 1.0 → 1.5 → 1.0)
- Dot EXPLODES into 200+ particles
- Particles drift and form outline of college campus buildings
- Campus outline glows with indigo/purple gradient

**Text Overlay:**
```
"What if your entire campus...
 fit in your pocket?"
```
- Font: Inter Bold, 48px
- Color: White with subtle glow
- Animation: Fade in word by word (0.5s per word)

**Audio:**
- SFX: Deep bass hit (50Hz) + whoosh (0.5s)
- Music: Silence → single synth pad note

**Technical Notes:**
- Use particle system (After Effects: Particle World / Motion: Particles)
- Campus outline: Simple 2D silhouette of 3-4 buildings
- Glow effect: Gaussian blur + screen blend mode

---

### SCENE 2 — THE PROBLEM (0:05 - 0:12)

**Duration:** 7 seconds

**Visual Sequence (2.3s per shot):**

**Shot 1 (0:05-0:07):**
- Student juggling 5 different app icons (attendance, payment, chat, library, timetable)
- Icons float around student's head in chaotic orbit
- Student looks overwhelmed, hands on head
- Text flash: "Too many apps."

**Shot 2 (0:07-0:09):**
- Parent holding phone showing 3 WhatsApp group notifications
- Notification badges: 47, 23, 156
- Parent looks confused
- Text flash: "Too much confusion."

**Shot 3 (0:09-0:11):**
- Admin staring at laptop with massive spreadsheet
- Spreadsheet has 500+ rows, tiny font
- Admin rubs eyes, sighs
- Text flash: "Too much manual work."

**Shot 4 (0:11-0:12):**
- Quick montage: Paper attendance register, manual fee counting, paper assignments
- All items fall/scroll rapidly

**Audio:**
- SFX: Ticking clock (120 BPM) accelerating
- Music: Tense minimal synth, building tension
- V.O.: "Too many apps. Too much confusion. Too much manual work."

**Technical Notes:**
- Quick cuts (0.5s per shot in montage)
- Desaturated color grading for "problem" scenes
- Slight camera shake for chaos effect

### SCENE 3 — THE REVEAL (0:12 - 0:18)

**Duration:** 6 seconds

**Visual Elements:**
- All chaos FREEZES (frame hold 0.5s)
- Screen shatters like glass (12-16 shards)
- Shards fly outward with motion blur
- Through the shards, phone appears floating
- Phone in gradient indigo/purple void
- Vishva ERP logo with glowing ring animation
- Ring pulses 3 times, expanding outward

**Text Overlay:**
```
VISHVA ERP
Smart Campus Management
```
- "VISHVA ERP": Inter Black, 72px, white
- "Smart Campus Management": Inter Medium, 24px, indigo-light
- Animation: Scale up from 0.8 to 1.0 with spring physics

**Audio:**
- SFX: Glass shatter (0.3s) + bass drop + uplifting synth chord
- Music: Bass drop → melodic synth pad (E minor chord)
- V.O.: "Introducing Vishva ERP — the AI-powered smart campus platform."

**Technical Notes:**
- Glass shatter: Use shatter effect or pre-rendered overlay
- Phone mockup: 3D render with reflection
- Logo glow: Animated gradient with glow layer
- Transition: Shards reveal (not simple cut)

## 3. Animation Specifications

### Transition Styles
| Transition | Usage | Duration |
|------------|-------|----------|
| **Glassmorphism Morph** | Feature-to-feature | 0.5s |
| **Particle Explosion** | Scene 1 intro | 1.0s |
| **Glass Shatter** | Scene 2→3 | 0.5s |
| **3D Card Flip** | ID card showcase | 1.0s |
| **Network Pulse** | Real-time scene | Continuous |
| **Counter Animation** | Stats display | 1.5s |
| **Spring Physics** | UI element entry | 0.3s |

### Text Animations
| Animation | Usage | Timing |
|-----------|-------|--------|
| **Word-by-Word Fade** | Headlines | 0.5s per word |
| **Slide Up + Fade** | Feature labels | 0.3s |
| **Pulse Glow** | Emphasis words | 1.0s loop |
| **Typing Effect** | AI responses | 0.05s per char |
| **Bounce In** | Stats/numbers | 0.5s |

### Color Transitions
- **Scene 1-2**: Desaturated (problem state)
- **Scene 3**: Full saturation (reveal)
- **Scene 4-7**: Indigo → Purple gradient shifts
- **Scene 8-9**: Stable brand colors

### 3D Elements
- **Phone Mockup**: 30° perspective tilt, soft shadow
- **ID Card**: Y-axis rotation (360°)
- **Network Lines**: Animated SVG with glow
- **Particles**: 3D particle system with depth

## 4. Audio Design

### Music Structure
| Section | Time | BPM | Instruments | Energy |
|---------|------|-----|-------------|--------|
| **Hook** | 0:00-0:05 | 60 | Single synth pad | Low |
| **Problem** | 0:05-0:12 | 80→120 | Tense synth, ticking | Building |
| **Reveal** | 0:12-0:18 | 120 | Bass drop, uplifting synth | Peak |
| **Features** | 0:18-0:45 | 120 | Electronic beat, pads | Steady |
| **Scale** | 0:45-0:53 | 120 | Orchestral layers | Building |
| **CTA** | 0:53-0:60 | 60 | Piano resolve | Calm |

### Sound Effects Library
| SFX | Description | Timing |
|-----|-------------|--------|
| Bass Hit | Low frequency impact (50Hz) | Scene 1 |
| Whoosh | Air movement sound | Scene 1, transitions |
| Glass Shatter | Breaking glass (0.3s) | Scene 2→3 |
| Ticking Clock | Clock tick (120 BPM) | Scene 2 |
| Notification Ping | App notification | Feature demos |
| Cash Register | Subtle "cha-ching" | Fee payment |
| Counter Tick | Number increment | Attendance |
| Keyboard Typing | Typing sounds | AI paper generation |
| Digital Scan | Tech scanning sound | AI grading |
| Heartbeat | Rhythm pulse | Scene 7 |
| Orchestral Swell | Strings + brass | Scene 8 |
| Piano Note | Single clean note | Scene 9 |

### Voiceover Specifications
- **Voice Type**: Male/Female, 25-35 age range
- **Tone**: Confident, warm, slightly excited (NOT salesy)
- **Accent**: Indian English (optional — neutral acceptable)
- **Pace**: Moderate, with pauses for visual beats
- **Recording**: Professional studio, 48kHz, 24-bit
- **Processing**: Light compression, no heavy effects

### Voiceover Script
```
[0:00-0:05] "What if your entire campus... fit in your pocket?"

[0:05-0:12] "Too many apps. Too much confusion. Too much manual work."

[0:12-0:18] "Introducing Vishva ERP — the AI-powered smart campus platform."

[0:45-0:50] "Everything updates in real-time. Attendance, payments, 
             chat, notifications — all synced."

[0:50-0:53] "Built for scale. Built for India."

[0:53-0:60] "Vishva ERP. Your campus. Your app. Download now."
```

## 7. Platform-Specific Cuts

### YouTube (16:9 - 1920×1080)
- Full 60-second version
- End screen with subscribe button
- Cards for related videos
- Description with download link

### Instagram Reels (9:16 - 1080×1920)
- 30-second cut
- Vertical reframe of key scenes
- Captions burned in (for silent viewing)
- Hook in first 3 seconds

### Instagram Stories (9:16 - 1080×1920)
- 15-second highlight reel
- Swipe up link to download
- Interactive poll sticker: "Which feature excites you most?"

### LinkedIn (16:9 - 1920×1080)
- 60-second version with professional tone
- Longer CTA with LinkedIn page link
- Thumbnail optimized for feed

### Twitter/X (1:1 - 1080×1080)
- 30-second square crop
- Captions for autoplay
- Link to landing page

### Facebook (16:9 - 1920×1080)
- 60-second version
- Thumbnail with text overlay
- Call-to-action button: "Learn More"

## 8. Quality Checklist

### Visual Quality
- [ ] All text readable at 1080p
- [ ] No compression artifacts
- [ ] Consistent color grading throughout
- [ ] Smooth animations (no dropped frames)
- [ ] Proper aspect ratios for all platforms
- [ ] Brand colors accurate

### Audio Quality
- [ ] Voiceover clear and balanced
- [ ] Music doesn't overpower VO
- [ ] SFX audible but not distracting
- [ ] No audio clipping
- [ ] Consistent volume levels
- [ ] Clean audio transitions

### Content Quality
- [ ] All features accurately represented
- [ ] No spelling/grammar errors
- [ ] Correct app screenshots used
- [ ] Call-to-action clear and visible
- [ ] Download link correct
- [ ] Brand name spelled correctly

### Technical Quality
- [ ] 1080p minimum resolution
- [ ] 30fps minimum frame rate
- [ ] H.264 codec
- [ ] File size under 50MB
- [ ] No interlacing issues
- [ ] Proper metadata

### Platform Optimization
- [ ] YouTube: End screen elements
- [ ] Instagram: Vertical crop looks good
- [ ] LinkedIn: Professional tone
- [ ] Twitter: Square crop works
- [ ] Facebook: CTA button visible
