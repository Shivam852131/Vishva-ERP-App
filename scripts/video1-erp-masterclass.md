## SECTION 3: THE 4 ATTENDANCE REVOLUTION (6:00 – 8:00)

**[On Screen: Split screen showing all 4 attendance methods side by side]**

> "Let me show you the feature that gets the most attention — attendance.
>
> Vishva ERP doesn't just do one type of attendance. It offers FOUR methods."

**[On Screen: QR Code demo]**

> "**Method 1 — QR Code.** Faculty displays a dynamic QR code. Students scan. Done. Takes less than a second per student."

**[On Screen: GPS Geofence demo]**

> "**Method 2 — GPS Geofence.** The app detects when a student enters campus using GPS coordinates. Auto check-in. No scanning needed."

**[On Screen: Face ID demo with liveness detection]**

> "**Method 3 — Face ID.** This is where AI comes in. Students enroll their face once. After that, they just take a selfie. The system uses TensorFlow.js and face-api models to verify identity with liveness detection — it detects blinks to prevent photo spoofing."

**[On Screen: Auto check-in flow]**

> "**Method 4 — Auto Check-in.** Background detection. Walk into class, your phone handles it silently.
>
> All four methods work in real-time with live Socket.IO updates. Faculty can see who's present, who's absent, override entries, and notify absentees — all live.
>
> No more paper registers. No more proxy attendance. No more confusion."

## SECTION 6: THE TECHNICAL EDGE (12:30 – 13:30)

**[On Screen: Architecture diagram — React Native, Node.js, MongoDB, Socket.IO]**

> "For the tech-savvy viewers — Vishva ERP is built with a modern stack.
>
> **Frontend** — React Native with TypeScript. Cross-platform. One codebase, Android and iOS.
>
> **Backend** — Node.js with Express. REST APIs + real-time WebSocket communication via Socket.IO.
>
> **Database** — MongoDB for flexibility, with a Prisma-defined PostgreSQL schema for structured data.
>
> **AI** — Multi-provider LLM chain with automatic fallback. TensorFlow.js for face verification ML models.
>
> **Payments** — Razorpay with encrypted college-specific credentials.
>
> **Deployment** — Docker containers on Render. Firebase for push notifications. Cloudinary for file uploads.
>
> And it's open source. The full code is on GitHub."
